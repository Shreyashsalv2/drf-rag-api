# Data

`gdpr.json` is the **Structured GDPR JSON dataset** by Guilherme Silveira
(https://github.com/gbasilveira/GDPR-JSON, commit `3c34bd9`), licensed under **CC BY 4.0**
(see `LICENSE-gdpr-json.txt`). It holds the text of Regulation (EU) 2016/679 (GDPR).

`scripts/make_samples.py` turns it into the sample documents in `samples/` (PDF, DOCX, Markdown).
The MIT license of this repository covers the code only. Not legal advice.
